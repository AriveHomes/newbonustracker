# Arive Homes Superintendent Bonus Tracker - Version 10

Version 10 adds an owner-facing Monthly Summary page while preserving the fixed $350 base bonus and 150-day single-family / 205-day townhome build-time rules.


Version 14 keeps the Version 13 Google Sheet synchronization and adds separate dashboard averages for Single Family and Townhome adjusted build time. Version 13 added optional Google Sheet synchronization for 30-day punch-list reminders. The connection requires a user-deployed Google Apps Script Web App and a private sync key stored in Apps Script Project Settings and in the tracker browser settings.
